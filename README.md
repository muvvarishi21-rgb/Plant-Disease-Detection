#  Plant Disease Detection using Deep Learning

##  Overview
This project detects plant diseases from leaf images using
Deep Learning (Convolutional Neural Networks - CNN).

The model is trained on labeled plant leaf images and can
classify whether a plant leaf is healthy or affected by a
specific disease. This system helps farmers and agricultural
researchers identify diseases early and improve crop yield.

---

##  Objectives
- Detect plant diseases from leaf images
- Build and train a CNN model
- Classify multiple plant disease categories
- Improve agricultural monitoring using AI
- Reduce crop loss through early detection
